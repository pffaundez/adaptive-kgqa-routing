# Data

This directory is intentionally excluded from version control except for documentation and placeholders.

- `raw/`: immutable source datasets and KG snapshots;
- `processed/`: normalized queries, features, and counterfactual outcome tables.

Every generated dataset should record its source version, license, checksum, transformation command, KG snapshot, and split policy. Do not commit benchmark data, model outputs, or credentials without confirming their licenses and repository policy.
